Para la portada utilicé un formato en cuadros en lugar de una tabla para mostrar los avisos.

El botón para agregar un nuevo contacto o una foto es un signo “+” y, en el caso de las fotos, añadí también un signo “–” para poder eliminar alguna si es necesario.

La barra de navegación está presente en todos los archivos HTML, de modo que sea más fácil moverse entre las diferentes secciones.

Las imágenes utilizadas corresponden a mascotas de mi familia.

Probé los archivos en tres navegadores: Chrome, Brave y Microsoft Edge.

Cuando algún campo del formulario no es válido, la página hace scroll automático hacia el error. Esto evita la confusión de que no pasaba nada al presionar “Enviar”, ya que la casilla con los errores aparecía en la parte superior y no era visible de inmediato.

En el archivo select.js se encuentran las funciones para añadir más contactos.
