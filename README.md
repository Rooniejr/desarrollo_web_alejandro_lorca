Tarea 3
Descripción
Aplicación web desarrollada en Python usando Flask, con funcionalidades para agregar avisos de adopción de mascotas, ver estadísticas y manejar comentarios. La aplicación utiliza HTML5, CSS3 y JavaScript (con Highcharts para los gráficos).

Detalles a tener en cuenta

Estadísticas:  
  - El tercer gráfico (gráfico de barras) muestra los datos por mes y año, para facilitar la lectura temporal.  
  - Los gráficos se generan dinámicamente usando Highcharts y llamadas `fetch` al servidor.

Comentarios:  
  - Los comentarios se muestran en la interfaz al lado izquierdo de la página para mejorar la legibilidad.  

Compatibilidad:  
  - La aplicación ha sido probada y funciona correctamente en los siguientes navegadores:
    - Google Chrome
    - Brave
    - Microsoft Edge

Validación:  
  - Todos los archivos `.html` y `.css` han sido revisados con los validadores de W3C y no presentan errores críticos.
